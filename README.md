# 📈 Compound Interest & Growth Calculator
A sleek, responsive web app that calculates compound interest over time and visualizes year-by-year financial growth using an interactive line chart.
## ✨ Features
* **Real-time Interest Calculation:** Computes future values based on initial deposit, annual rate, and time horizon.
* **Interactive Charting:** Displays visual balance growth over time powered by Chart.js.
* **Modern Dark Theme:** Styled with a custom slate, steel blue, and dark charcoal palette.
* **Responsive Layout:** Side-by-side dashboard layout for desktop and stacked views for mobile devices.

## 🛠️ Tech Stack
* **HTML5** – UI structure
* **CSS3** – Custom dark mode styling and CSS Grid layout
* **JavaScript (ES6+)** – Mathematical calculations and DOM manipulation
* **Chart.js** – Interactive data visualization library
